# Ahsan Ali Portfolio

Next.js portfolio customized for Ahsan Ali, with responsive desktop/mobile hero video, contact links, CV, and portfolio content.

## Deploy on Vercel

1. Extract this ZIP.
2. Put the extracted folder in a GitHub repository.
3. In Vercel, import that repository.
4. Keep the detected framework as **Next.js**.
5. Build command: `npm run build`
6. Deploy.

No environment variables are required for the current site.

## Video

- `public/hero-bg-video.mp4` — 2560×1440 desktop version.
- `public/hero-bg-mobile.mp4` — 810×1440 mobile crop.

The supplied 16:9 source was encoded at a high-quality CRF 18 setting and the mobile version was reframed to 9:16 rather than squeezed/distorted.
